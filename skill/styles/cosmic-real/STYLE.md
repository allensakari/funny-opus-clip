# cosmic-real · 写实宇宙

数说世界的一种固定风格，源自 S012《人类只是过客》（2026-10-15 用户逐轮修改；2026-10-18 出 YouTube 纯英文版）。
- 适合：宇宙、时间尺度、地球和太阳的命运、人类在宇宙里的位置这类「大而无情」的题材。要能拍成一部情绪片：希望 → 绝望 → 挣扎 → 宿命。
- 产出：无配音、按配乐卡点的写实 3D 短片，16:9 横版；短版约 2 分钟，长版 3–3.5 分钟。

| 路径 | 内容 |
|---|---|
| `templates/S012/gl.py` | GL 层：`GL.scene(t, SCN)` 渲宇宙，`GL.trans(A, B, u, mode, focus, t)` 做转场 |
| `templates/S012/space.glsl` | 光线追踪的地球（NASA Blue Marble / 云 / Black Marble 城市灯光）、太阳、红巨星、月球、星场、银河 |
| `templates/S012/trans.glsl` | 10 种宇宙转场（见下） |
| `templates/S012/film.py` | 2:11 版：镜头表 `SH`、文字工具 `T_` / `SRC` / `counter`、字幕、拼帧 `frame()` |
| `templates/S012/film_3min.py` / `film_3m30.py` / `film_3m30_v5.py` | 3 分钟版、3:06 长版、3:31 v5；都是在 film.py 上打补丁（换配乐、拍点网格、镜头表） |
| `templates/S012/beatmap.py` · `extend_music*.py` | 测拍、在强拍上剪接延长配乐 |
| `templates/S012/score.py` | 音效（按镜头名 `at('name')` 落点）+ 配乐混音 |
| `templates/S012/en_text.py` | 纯英文版译文表（`SUB=pure`） |
| （参考成片不随仓库提供） | 纹理：NASA Blue Marble / Black Marble（公有领域）放期目录 `tex/`；配乐自己生成 |

## 和 shushuo 默认流程不同的地方

| 项 | 默认 | cosmic-real |
|---|---|---|
| 配音 | A2 配音 | **不配音**：画面大字 + 底部中英字幕 |
| 画面 | skia 2D / moderngl 程序动画 | 光线追踪写实 3D（`space.glsl`）+ 真实照片（NASA / ESO 等公有领域或 CC BY） |
| 画幅 / 帧率 | 竖版 30 fps | **横版 1920×1080、60 fps**；草稿 `DRAFT=1` 是 960×540、30 fps |
| 配乐 | Kevin MacLeod / 合成 | 一首完整的情绪曲（S012 用 Lyria 3.5 的大提琴 + 钢琴 + 鼓，B 小调 110 BPM），**镜头卡在拍点上**；长版在强拍上剪接延长 |
| 时长 | 60–90 s | 短版约 2:10；长版 3:00–3:30（B站、YouTube） |
| 水印 | 黄点锚定 + 片尾标志 | 黄点锚定，但**没有片尾标志**：停在最后一句话上（用户 2026-10-15） |

不变的部分：一手来源、`stats.py` 可复现、四个确认节点、`engine/finalize.py` 出片（−14 LUFS、12 Mbps）、`transqc.py` 逐帧查闪烁。

## 情绪结构（跟着音乐走）

S012 的段落锚点都取自配乐：钢琴独奏 = 希望，鼓进 = 绝望，最强段 = 人类的努力，回落 = 屏息，再起 = 宿命，高潮 = 吞没，回到慢 = 熄灭。
- **开头「结局先行」**（用户选的方案 A）：第 0 帧就是结局的远景，大字从第一帧完整显示（「76 亿年后 / 太阳会吞掉地球 / 我们能逃到哪里？」），约 2.6 秒后熄灯转进希望段。
- **努力段越长，结局越无力**（用户：「越努力，对最终结局的无力感对比越强烈」）：长版把努力分两幕，地球上的反抗（寿命、种子库、核聚变、DART）→ 飞向宇宙（登月、空间站、帕克、机智号、韦布、黑洞、冥王星、旅行者号）。但别太长：用户嫌 v5 的努力段冗长，v6 压缩到每镜 2 小节。
- **结尾**：黑场一句话（「宇宙不会记得我们来过」），不放片尾标志；长版去掉结尾心跳。

## 画面规则

- **镜头一般 ≤ 5 秒，重要情绪段可到 8 秒**（用户 2026-10-15）；字要来得及读完，「有些镜头切得过快，字还没看清楚」时段内少切几刀，段落锚点不动。
- **每镜缓慢后拉**：`dolly(a, b, u)`，相机从近到远慢慢退。
- **配色随情绪走**：深蓝 → 血红 → 纯黑。数字用冷蓝 `ACC`，危险 / 时间用红 `RED`。
- **右上角计数器**「距今 + X 年」（`counter()`）：只在宿命段出现，数字越跳越大。
- **真实照片**：`photo_focus()`（满屏、慢推到某一点，左侧压暗保证字可读）、`photo_panel()`（画框）。每张照片右下角写来源和授权。
- **画面里已经有大字的镜头，不再出底部字幕**（用户：不要重复显示；`.srt` 仍保留全部台词）。最后几个镜头的字放在画面正中。
- 震撼的画面靠层次和体量，**不用闪白、抖动、缩放冲击**（S012 撞击镜头：火球尾焰 → 蘑菇云 → 贴着球面的冲击波 → 几百块燃烧的抛射物 → 尘幕）。
- 字体：标题用霞鹜文楷 + Cormorant Garamond（`E.tx`，math-beauty 引擎），数字 `lf=E.CG_SB`，来源小字 `SRC()` 用 Cormorant 斜体。

## 转场

`trans.glsl` 的 10 种，中点落在拍上，**每个切点按情绪选方式和长度**（用户 2026-10-15 指出转场太统一）：

| 编号 | 名字 | 用在 |
|---|---|---|
| 0 | 熄灯 lights-out | 希望 → 绝望、段落收尾 |
| 1 | 红移 redshift | 时间推进、宿命 |
| 2 | 时间流逝 time-smear | 跨越很长的时间 |
| 3 | 引力透镜 lensing | 慢段、屏息 |
| 4 | 化为尘埃 dust | 灭绝、消失 |
| 5 | 曲速 warp | 只留给升空、旅行者号 |
| 6 | 日食 eclipse | 太阳相关 |
| 7 | 光柱 god-ray | 希望段 |
| 8 | 时空涟漪 ripple | LIGO、引力相关 |
| 9 | 烧穿成黑 burn | 结尾、熄灭 |

节奏：希望段长而慢；绝望段中等，鼓的重拍上偶尔硬切；努力段随渐强越切越快，飞向宇宙以**重拍硬切**为主，加匹配剪辑（黑洞光环 → 冥王星）；屏息极慢；吞没在高潮拍上硬切；熄灭最慢。

## 卡点

- `beatmap.py` 测出拍点，镜头表用半小节编号 `h(n)` 写（`S(n0, n1, scene, draw, mode, focus)`），切点放在偶数半小节 = 小节第 1 拍。
- 剪接延长的配乐每段会提前 30 ms（交叉淡化），拍点网格要跟着音频走（`film_3m30.py` 的 `XF`）。
- **不要自动吸附到「最响的一下」**：v5 用起音包络把切点挪到最强击打上，用户反馈「卡点反而更差」，v6 撤销了。升空 / 吞没这些位置本来就是底鼓 + 贝斯砸下的强拍，更尖的那几下是军鼓滚奏。
- 改了卡点就出一版 `DRAFT=1` 草稿给用户看（`build/review/草稿_*.mp4`），不要只看拍点表。

## 声音

- 配乐压在主位；音效约低 7 dB，按镜头名落点：无线电「哔」、火箭轰鸣、阿波罗 Quindar 双音、旅行者号载波、心跳、钟表越走越快、星星熄灭的轻响；每种转场有自己的声音（熄灯 = 开关闷响，红移 = 下滑扫频，曲速 = 上扬呼啸……）。
- 抖音版另出只有音效的 `_无BGM.mp4`。
- **Lyria 配乐的版权**：商用 / 变现条款没写明（见记忆「变现前提核实」）。上 YouTube 变现前换成原创合成或有明确授权的曲子；做新一期时优先用原创合成。

## 版本

- 不覆盖旧版本：每个版本一个文件（`film_3min.py`、`film_3m30.py`……），配乐也带后缀（`lyria_a_1_3min.wav`、`_3m30.wav`、`_3m30b.wav`），草稿按 `v1、v2…` 存进 `build/review/`。
- 用户可能回头要旧版本（S012 回头要了 v5）：开新版本前把当前文件复制一份到 `build/film_<版本>_vN.py`。
- **YouTube 纯英文版**：`SUB=pure`。film.py 在 `import engine` 之后把 `E.tx` 包一层 `en_text.tr()`，画面上出现没翻译的中文会直接报错；`BRAND_LANG=en` 换英文水印；封面另写 `make_cover_en.py`。

## 渲染

```
cd episodes/S0NN_xxx/show
DRAFT=1 python film_xxx.py --part i 8      # 草稿，看节奏和情绪
python film_xxx.py --still t …              # 样帧
CUT=xxx python score.py                     # 音效 + 配乐 → build/show_xxx/mix.wav
python film_xxx.py --part i 8               # i = 0–7 并行，拼接后 ffprobe -count_packets 核对帧数
python ../../../engine/finalize.py build/…/video.mp4 build/…/mix.wav 发布/xxx.mp4
```
GL 渲染很吃 GPU：不要同时跑别的重任务。
