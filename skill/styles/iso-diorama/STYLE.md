# iso-diorama · 等距微缩

数说世界的一种固定风格，源自 S019《石油，越用越多》的风格样片（2026-10-21：用户在工程蓝图 / 剪纸地层 / 等距微缩三版 10 秒样片里选了等距微缩）。
- 适合：资源与能源（石油、水、电、粮食）、城市、交通、工业这类「东西从哪来、到哪去」的题材。要能拍成一块浮在空中的小场景：地面上有设施，切开的侧面露出地下或内部。
- 产出：纯音乐 + 中英双字幕的动画短片，横版和竖版各一份。

**这是一个新风格**：目前的规则只来自一段 10 秒样片。S019 正片做完后，按用户的修改补全「结构公式」「章节卡」「结尾」和「经验」。

| 路径 | 内容 |
|---|---|
| `iso_diorama.py` | 画面工具包：网格、场景、GL 渲染、合成、叠加层 |
| `templates/S019_style_test/` | 风格样片：`common.py`（时间轴、字幕、配乐）+ `iso.py`（场景）。复制到期目录里用，`common.py` 按期目录的层级算根目录 |
| `episodes/S019_石油越用越多/style_test/build/C_等距微缩.mp4` | 参考样片（30 fps） |

## 和 shushuo 默认流程不同的地方

| 项 | 默认 | iso-diorama |
|---|---|---|
| 配音 | A2 配音 | **不配音**，纯音乐 + 中英双字幕（用户 2026-10-21） |
| 字幕 | 数字跳格 `odo` | 本风格自己的字幕：思源黑体 Bold 墨色，英文 Nunito ExtraBold 55% |
| 帧率 | 30 fps | 60 fps（样片用 30 fps） |
| 画幅 | 默认只出竖版 | 横版、竖版都出（`VERT=1` 出竖版） |
| 水印 | 黄点锚定 | 全片不叠水印，片尾只放标志（同 print-cartoon） |
| 配乐 | Kevin MacLeod / 合成 | 沿用 print-cartoon 的两条路线：合成电子乐（`print_cartoon_audio.py`）和 Lyria 3.5，两版都出 |
| 时长 | 60–90 s | 先做完整版，再用剪辑表压到约 90 s（同 print-cartoon，用 `print_cartoon.py` 的 `seg_table` / `film2out` / `caps_kept` / `render_main`） |

不变的部分：一手来源、数字可复现（`stats.py`）、四个确认节点、悬念链、`engine/finalize.py` 出片（−14 LUFS、12 Mbps）、两份 QC。

## 画面语言

**一块浮在空中的小场景**
- 主体是一块切开的方块（样片：半宽 2.3 的土块），顶面是场景，两个切面露出分层。
- 它浮在暖白底色上，下面一片柔和的接触阴影（`composite(contact=…)`）。**不要放地板**：太阳光的阴影投到大地板上会出现阴影图边缘的硬线（样片第一版踩过）。
- 东西「变多」「变少」都在模型上演：储油层变薄、油桶一个个弹出来堆起来、方块往下长出新的地层、新油藏从切面上鼓出来。

**相机**
- 正交等距相机 `iso_vp(target, 半高)`，固定从 +x / +y / +z 方向看（`VIEW_DIR`），永远看到顶面和两个切面。
- 镜头运动只用两种：**目标点平移**（跟着方块往下长、往旁边扩）和**半高缩放**（推近 / 拉远）。都用 `eio` 缓动、落在拍点上。
- 样片竖版：半高 6.4（开场）→ 7.3（方块长到两倍深）。

**光和材质**
- 一个暖色太阳 `LIGHT`（从左上前方照来，+z 切面是亮面）+ 天光（上暖下冷）+ 5×5 PCF 软阴影 + 4× MSAA。
- 所有东西都是**哑光低多边形**：方块、圆柱、球、圆锥四种网格（`BOX / CYL / SPH / CONE`），不加贴图。
- 只有「主角物质」用光泽材质 `gloss=1`：高光加一圈金色边光（石油、以后的水 / 熔岩可以照用）。
- 合成：上下两端**移轴虚化**（`composite(focus_y)`，清晰带跟着主体走）+ 很淡的暗角。

**颜色**（`PAL`，样片定下的，后续可按题材加）

| 用途 | 颜色 |
|---|---|
| 底色 | 暖白 `#FFF6EA` |
| 地面 | 草绿 `grass` / 树 `tree` / 树干 `trunk` |
| 地层（由浅到深） | `sand` → `shale` → `cap` → `deep` → `base`，越深越暗越红 |
| 主角物质 | 石油 `oil` `#2A2226`（光泽） |
| 设施 | 青绿 `teal`、番茄红 `red`、奶白 `cream`、钢灰 `steel` |
| 叠加层 | 墨色 `INK`、白卡 `CARD`、番茄红 `TOMATO`（坏消息 / 强调 / 盖章）、金 `GOLD` |

**叠加层**（skia，盖在 3D 上面）
- **数据卡** `counter_card`：白色大圆角卡片 + 柔阴影，小字标签、大数字（Nunito Black）、单位在右。
- **盖章** `stamp_pill`：番茄红药丸 + 白字，弹入、斜 8°（样片的 ×2.5）。
- **标签** `pill_label`：白色小药丸 + 红字，**跟着 3D 物体走**：用 `project(VP, 世界坐标)` 算屏幕位置，每帧重算。
- 来源标注沿用账号规则：数字下方小字标「机构 · 年份」。

## 字幕

- 顶部居中：竖版中文 60 px，基线 y=268；横版中文 56 px，基线 y=118。英文在下方，透明度 55%。
- 太长时在第一个逗号处断成两行（`wrap2`）。每秒不超过约 6 个汉字，每句至少显示 2 s。

## 竖版布局（样片）

| 区域 | y 范围 |
|---|---|
| 字幕 | 约 200–420 |
| 数据卡 | 452–622（两张并排，x 70 / 550，宽 460） |
| 小场景 | 约 600–1550（方块顶面不要被数据卡挡住；树、设施放在方块后半部分时可以露在卡片后面） |
| 平台遮挡区 | 右侧 x>920、y 900–1620，底部 y>1540：不放标签和关键数字 |

## 制作要点

- **性能**：竖版一帧零点几秒（M5，含 GL 渲染和 skia 合成）。正片用 `render_main` 分段并行，每个进程自己建一个 GL 上下文（`_gl()` 首次调用时创建）。
- **几何每帧重建**：`build(t)` 每帧返回一个新的 `Scene`，动画直接写在坐标里（旋转用 `R=rot(...)`、`pivot=` 绕点转）。不需要骨骼或关键帧。
- **圆柱的尺寸**：`CYL` 是直径 1、高 1 的单位圆柱；`size=(直径, 高, 直径)`。
- **透明通道**：`render()` 返回未预乘的 RGBA，空白处 alpha=0，由 `composite()` 垫底色和接触阴影。
- **样片里踩过的坑**：
  - 阴影图范围外被当成「在阴影里」，整片地板发灰 → 着色器里范围外一律算亮（已写进工具包）。
  - 数据卡和方块顶面、设施互相挡：先定数据卡的位置，再调相机目标点让方块落在卡片下方。
  - 油桶、储罐、抽油机挤在一起：设施沿方块的对角线分开摆，抽油机靠近 +z 切面（井筒要画在切面上才看得见）。
  - 切面上的「新油藏」一开始像黑洞：加大光泽球的厚度（突出切面）和金色边光后才读成「油」。

## 经验（S019 正片）

- **全屏卡片已进工具包**：`wipe`（章节卡：奶白面板 + 番茄红编号药丸 + 思源黑体 Heavy 逐字弹出）、`theme_card`、`end_logo`。场景叠加层在章节卡完全盖住时不画（`t0 − 0.5 … t0 + 0.55`）。
- **QC**：`text()` 在 `SHUSHUO_QC=1` 时把每个文字框（按画布变换算好位置）登记进 `brand.QC`；期目录放一个 `qc_render.py`（`W, H, T, FPS, frame(i)`），用 `RENDER=qc_render python ../../engine/qc.py [--land]` 跑。
- **转场 QC 抓到的三种 3D 闪烁**：
  - 共面 z-fighting：草皮盖子的底面和最上层地层的顶面都在 y=0，相机一动就闪 → 盖子抬高 8 mm。任何两个盒子都不要共用一个可见平面。
  - 每帧移动的接缝：把一层拆成「亮 / 暗」两个盒子、分界线每帧移动，切面上会出现阴影锯齿 → 整层用一个盒子，按时间渐变颜色和光泽。
  - 阴影边缘爬行：阴影图的像素比屏幕粗时，相机漂移会让阴影边缘抖 → 阴影图 4096、光照范围收到 7.5。
- **转盘漂移**：每个镜头的相机都带一个很慢的偏航 ±7° 和缩放 ±2.5%（`film.py` 的 `vp()`），解决「只有抽油机在动」的静止段。
- **字体**：Nunito 没有中文字形，`stamp_pill` 遇到汉字自动换思源黑体；图表上带「：」「美元」的标签也要用中文字体。
- **滚动计数器按真实逐年数据走**：数字会上下起伏（2002 年储采比 50.2、2003 年 48.2），转场 QC 会报单帧闪烁，用 `--ignore` 跳过并在节点 ③ 说明；不要为了平滑而编造中间值。
- **闭环结尾**：最后一个镜头 = 第 0 帧的构图，标志放在它之前；`qc.py` 的「片尾标志出现时仍可见」会报这一段，是有意的。

## 新一期怎么开工

1. 按 shushuo 流程做到节点 ①。
2. 复制 `templates/S019_style_test/` 到期目录，`common.py` 改成本期的时间轴 / 字幕 / 配乐；场景写成 `build(t)` + `camera(t)`。
3. 正片换成 print-cartoon 的出片方式：60 fps、横竖两版、`render_main`、两版配乐、`SEG90` 剪辑表。注意 `render_main` 调用的是 `frame(t, surf)`（样片的 `frame(t)` 要加一个参数），并且 `print_cartoon` 和本工具包都按 `VERT` 环境变量定画幅，两边要一致。
4. 节点 ③ 给横版和竖版的样帧拼图和两版配乐；用户确认后再做剪辑版。
5. S019 定稿后，把章节卡、主题句卡、投票卡、片尾的样式补进本文件。

## 经验（S019 节点 ③ 用户反馈，2026-10-21）

- **每个地点要有自己的天空和地面**（用户：「一直就是同一个背景，完全是靠字幕」）。全片同一块奶油底、同一块草地土块，观众只能读字幕。现在的做法：
  - `composite(..., bg=(上, 下[, 横向]), decor=函数)` 换渐变底色，`render(..., sun=, sky=)` 给阳光和天光染色；
  - 工具包里有 `clouds` / `sun` / `snow` / `birds` / `grid`（2D，画在土块后面或前面，出入画面都会渐隐）；
  - 土块顶面用 `lid=` 换地面（雪地、雨林、干草、沙漠），换上当地的道具（松树和矿卡、圆冠树和河、仙人掌和成片的抽油机、棕榈）。
  - 期内写一个 `env_of(场景, t)` 表，相邻场景之间（比如土块转身的那一下）在两套颜色之间渐变。暗下去的段落（「到底了」）只压暗下半部分，字幕区保持浅色。
  - 3D 输出改成预乘 alpha（清屏为透明黑），深色底上边缘不再有奶油色白边。
- **章节卡至少停 2 秒**（用户：「切换太快了字都没看清」）。原来标题完整可见不到 1 秒。`wipe(..., hold=2.0)` 让卡片多停一小节；期内的时间轴继续按「故事时间」写，`timeline.real()` / `story()` 在每张章节卡处冻结故事 2 秒，`film.frame(T)` 先换算成故事时间，音效事件注册完再统一换算成输出时间。配乐在这一小节最后一拍放一段军鼓 / 嗵鼓过门，Lyria 版本在这里重复前一小节。
- **阴影 bug（2026-10-21 修好）**：阴影那一遍的顶点格式写成了 `'3f 36x'`（步长 48 字节），实际每个顶点是 10 个 float（40 字节），阴影图读到的是错位的几何体，会凭空出现大片阴影、随物体数量变化而闪。改成 `'3f 28x'` 后阴影正确。上面「三种 3D 闪烁」里的阴影问题多半就是它。镜头推拉时，阴影范围（`light_vp` 的 extent）要固定，不要跟着镜头缩放，否则阴影会抖。
- **v3 方向（用户 2026-10-21：动画太单调 → 镜头动起来、小人演戏、物理化比喻、节奏更快；配乐要轻快俏皮）**：样片 `episodes/S019_石油越用越多/sample_v3/`：桌面世界地图（Natural Earth 陆地格子）上站着各国土块，一镜到底在国家之间飞；工人、会计小人（胶囊 + 眼睛 + 安全帽）；挖掘机、井架、喷油；储量变成一桶一桶往上叠的塔（1 桶 = 100 亿桶），镜头跟着塔往上抬；约每 1.5–2 秒一个新动作。
