# print-cartoon · 印刷卡通

数说世界的一种固定风格，源自 S015《你总排到慢的那队》（2026-10-17 ～ 18，用户逐轮修改后定稿）。
- 适合：生活里的概率、排队 / 等待、选择、比较、「为什么总是我」这类题材。要能拍成一群小人在一个日常场景里的小故事，主角是「你」。
- 产出：纯音乐 + 中英双字幕的动画短片，横版和竖版各一份。

| 路径 | 内容 |
|---|---|
| `print_cartoon.py` | 画面工具包 |
| `print_cartoon_audio.py` | 配乐 / 音效工具包 |
| `templates/S015/` | 整期参考工程：film / score / timeline / stats / lyria |
| `episodes/S015_你总排到慢的那队/发布/你总排到慢的那队_90s*.mp4` | 参考成片 |

## 和 shushuo 默认流程不同的地方

| 项 | 默认 | print-cartoon |
|---|---|---|
| 配音 | A2 配音 | **不配音**，纯音乐 + 中英双字幕 |
| 字幕 | 数字跳格 `odo` | 本风格自己的字幕：思源黑体 Bold 加套色阴影，英文 Nunito |
| 帧率 | 30 fps | 60 fps |
| 画幅 | 默认只出竖版 | 横版、竖版都出（共用一个世界坐标，`VERT=1` 出竖版） |
| 水印 | 黄点锚定 | 全片不叠水印，片尾只放横排黑字标志 |
| 配乐 | Kevin MacLeod / 合成 | **合成电子乐**或 **Lyria 3.5**，两版都出。不用《千年以后》卡点（用户 2026-10-18 试过，觉得不适合） |
| 时长 | 60–90 s | 先做完整版（约 2 分钟），再用剪辑表压到**约 90 s** |

不变的部分：一手来源、数字可复现（`stats.py`）、四个确认节点、`engine/finalize.py` 出片（−14 LUFS、12 Mbps）。

数据来源在画面里有两种情况：
- **用自己的模拟算出来的数字**：在卡片或图表下方标「模拟：参数……」。
- **引用别人的数字**：照旧标「机构 · 年份」。

## 画面语言

**纸和墨**
- 米色纸 `PAPER #F2ECDF`，墨色 `INK #2A2A3C`，卡片白 `CARD #FFFCF4`。
- 每帧最后盖一层孔版颗粒 `GRAIN_IMG`。
- 色块都带套色偏移阴影：`riso_rrect`，以及 `text(..., riso=3~5)`。

**颜色的固定含义**

| 颜色 | 用途 |
|---|---|
| 品牌黄 `YOU #F5C247` | 只给「你」和章节卡 |
| 番茄红 `TOMATO` | 坏消息、强调、盖章、主题句里的关键词 |
| 青绿 `TEAL` | 好的结果、对的做法 |
| 其他颜色 | 路人用 `SHOP` 里的颜色（不含黄色） |

**角色：胶囊小人（`bean`）**
- 没有手脚，只靠眼神 `gaze`、嘴 `mood`、眉毛 `brow` 演戏，会眨眼。
- 走路时身体上下颠，身后带三条速度线（`draw_beans` 自动画）。
- 「你」的头上有 ▼ 和「你」字。

**动作卡拍**
- 120 BPM，一拍 0.5 s。
- 每次前进、结账、弹出都落在拍点上（`snap()`）。
- 排队模型 `Lane`：离开时间落在拍点上，后面的人在 0.55 s 内补上。任何「一个接一个」的题材都能用。

**叠加层**
- 大数字 `big`：Nunito Black，弹入。
- 盖章 `stamp`：「最快！」「又是我？！」「没人插队」。
- 想法气泡 `bubble`。
- 纸卡片 `card`：用于计数、数据对比。
- 颜色语义要固定，例如「你这队最快」是黄点、「别的队更快」是红点。

**字体**

| 用途 | 字体 |
|---|---|
| 字幕 / 标签 | 思源黑体 Bold / Heavy |
| 章节卡、主题句 | 得意黑 `SmileySans-Oblique` |
| 英文、数字 | Nunito Black / ExtraBold / SemiBold |

## 结构公式（每期都按这个排）

**1. 钩子（0–8 s）：互动提问**
- **第 0 帧**就有场景和选项：A / B / C 标签随拍子跳动，字幕直接问观众（「三条队，你选哪一条？」）。
- **约 2.4 s**：「你」做出选择，选中的那一项变黄，伴随「叮」一声。
- **选完马上让结果变坏**：别的队每拍走一个人，你这队不动，盖章「又是我？！」。
- **约 4 s**：砸出反常识的大数字（「2/3」），字幕把它说成一句话。

**2. 四到五个章节**
- 每章开头一张**章节卡**（`wipe()`）：品牌黄面板加番茄红前导斜边，从右侧扫入；黄色章节号先出，标题用得意黑逐字弹出，英文淡入，然后扫出。
- 第一张章节卡兼片名卡，传入 `title`。
- **纯文字**，不要小票、条形码这类装饰（用户 2026-10-18）。
- **不要深色面板**（用户 2026-10-18：和明亮的调子不搭）。

**3. 每章的写法**
- 先用场景演出问题，再给数字，最后给一张数据卡或图表。
- **任何镜头不能超过约 3 秒只有字幕在变**（用户 2026-10-18 嫌拖沓）。没有新信息时，用这些方法让画面动起来：
  - 小人入场、镜头推近
  - 标签逐个弹出、高亮在选项间跳
  - 扫描线扫过、数字往上数
  - 盖章、眼神乱瞟、气泡轻晃

**4. 结尾三段**
- **主题句卡**（`theme_card`，约 4.5 s）：用一句话说出这期讲的道理，逐字打出，关键词用番茄红；下面浮出一行小字作为情绪收尾。
  - S015 的主题句：「你不是运气差，只是总盯着比你快的那一队。」小字：「说到底，我们都排在同一队里」。
  - 竖版用 `lines_v` 拆成 3 行。
- **投票卡**（`vote_card`，约 3 s）：把选择题抛给评论区，例如「换队扣 1，死守扣 2」。
- **片尾**（`end_logo`，约 2 s）：只放标志，**不加口号**（用户 2026-10-18 删掉了「关注数说世界，用数字看懂日常」）。

## 字幕

- 放在顶部。
  - 横版：中文 56 px，基线 y=128；英文 28 px，基线 y=182。
  - 竖版：中文 62 px，基线 y=312（字顶约 258，低于平台顶部的 165）；英文 32 px。
- 竖版中文过长时，优先在逗号处断成两行（`wrap`），不能把「10%」这类数字和符号拆开。
- **每句至少显示 2 s**。剪辑后不足 1 s 的字幕要去掉（`caps_kept`）。

## 竖版规则（用户 2026-10-17 指出字太小、超出安全区）

- **世界坐标**：放大 `ZV=1.25`、下移 `VY=85`，能看到 x 0–864（收银台加约 5 个人）。
- **安全区**：
  - 字幕：顶在 y≈258。
  - 关键信息：在 y 1540 以内。
  - 右侧 x>930、y 900–1620 是平台按钮区，「你」和关键标签不要放进去。
- **叠加层**：用 `ov(c, 横版矩形, (竖版中心x, 中心y, 最大宽))` 重新放置。
  - 大数字放在三条队下方，y≈1330–1420。
  - 卡片放在画面中部，y≈900。
  - 卡片里的字号乘 `FS`（竖版是 1.3）。
- **图表**：竖版按竖屏原生重画。
  - 坐标轴数字 ≥ 32 px，标注 ≥ 42 px，说明 ≥ 26 px。
  - **不要把横版图表整体缩小塞进来**（S015 初版 0:48 的图在手机上看不清）。
- **竖版不画背景货架**：那块地方留给字幕。
- **其他元素**：小人图标在竖版里放大（0.62 倍），配 46 px 的说明文字。

## 配乐与音效

**合成电子乐**（参考 `templates/S015/score.py`）
- F 大调 I–vi–IV–V，120 BPM。
- 每段的配器：

| 段落 | 配器 |
|---|---|
| 钩子 | 只有铺底和贝斯 |
| 第一章 | 律动加 epiano 旋律 |
| 「卡住」段 | 只留木鱼秒表、单音贝斯和硬币声 |
| 图表段 | 马林巴琶音逐渐加密 |
| 第四章 | 马林巴高八度 |
| 结尾 | 八音盒 |

- 117 s 一个 F 大三和弦，121 s 钟声。
- hi-hat 就是收银扫码的「嘀」（2.7 kHz）。

**Lyria 3.5**（`templates/S015/lyria.py`，每首 0.08 美元，密钥只从 `.gemini.env` 读）
- 提示词按片子的段落时间写，固定「EXACTLY 120 BPM」，不要人声。
- 生成 3 首，用 `episodes/S011_地球上所有的水/show/beatmap.py` 测拍，看强拍是否落在偶数秒、能量曲线是否贴合段落。
- 选最贴的那首，用 `bar_edit` 按强拍剪接对齐段落（S015 用的是 `lyria_a_1`，补了一个安静小节，又把结尾温柔段重复了一遍）。
- 和合成版用 `match_rms` 对齐响度。

**音效**
- 由画面里的 `ev()` 事件驱动：每次结账一声同调的铃，弹出用 pop，盖章用底鼓加拍手。
- 章节卡：`swoosh` 进出，盖住时一下低音，逐字打字声。
- 换队用 `boing`，倒霉用 `womp`，扫描用一串上行的「嘀」。

## 剪辑表：先做完整版，再压到约 90 s

- 完整版按「时间够讲清楚」来排（S015 是 124 s），然后在 `timeline.py` 写 `SEG90 = [(片中起, 止, 速度), …]`。
- **静止停留直接剪掉**；有动作但慢的段落用 2 倍速（动作落到 8 分音符，仍然踩拍）。
- **保持原速的**：章节卡、关键演示、主题句、投票卡。
- 边界都取整秒。
- **画面**：`render_main(frame, 总长, build, __file__, tmap=lambda T: out2film(T, SEG90))`。
- **音效**：用 `film2out` 映射时间，落在剪掉部分的事件丢弃。
- **配乐**：`remap_music(mus, SEG90)`，每个保留段按 1× 播放自己那几小节。
- S015 从 124 s 压到 93.5 s。

## 出片清单

- `CUT=90` 出 4 个文件：横版 / 竖版 × 电子乐 / Lyria。
  - 命名：`片名_90s.mp4`、`片名_90s_Lyria.mp4`、`片名_90s_竖版.mp4`、`片名_90s_竖版_Lyria.mp4`。
  - 字幕文件：`片名_90s.srt`（包含主题句）。
- 每次改完都要用 `--still` 抽帧自查，竖版和横版都看：
  - 0.6 s / 3.9 s（钩子）
  - 每张章节卡
  - 图表
  - 主题卡
  - 投票卡
  - 片尾
- 成片再用 ffmpeg 在剪接点前后抽帧，确认没有跳帧或穿帮。

## 新一期怎么开工

1. 按 shushuo 流程做到节点 ①（选题、来源、`stats.py`）。如果数字来自模拟，参数和结果写进 `data/stats_out.txt`。
2. 复制 `templates/S015/` 的 `film.py`、`score.py`、`timeline.py` 到期目录。
3. 期目录里引入工具包：`sys.path.insert(0, ROOT + '/skill/styles/print-cartoon')`。
   - 已经抽进 `print_cartoon.py` 的部分，改成从工具包引用。
   - 只重写场景函数（`sc_*`）、`CAPS`、`WIPES`、`THEME`。
4. 节点 ② 给出：钩子的互动问题、章节标题、主题句（两种写法让用户选）、投票题。
5. 节点 ③ 给出完整版的样帧拼图（横版和竖版）和两版配乐；用户确认后再做 `SEG90` 剪辑版。

## 经验（S015）

- **钩子的演进**：
  - 第一版只有提问字幕和慢慢挪动的队，用户说不过关。
  - 第二版加了选项和 2/3，还是嫌弱。
  - 定稿：选中的瞬间别的队开始飞快前进、你这队不动，加盖章。冲突要发生在选择之后的 1 秒内。
- **转场的演进**：
  - 小票扫屏加条形码 → 用户嫌装饰多。
  - 深色纯文字面板 → 用户问「为什么用深色」，嫌突兀。
  - 定稿：品牌黄纯文字面板。
- **画面停留**：用户嫌拖沓，有两次修改：
  - 给每个只有字幕在变的镜头加动作；
  - 用剪辑表从 124 s 压到 93.5 s。
- **主题句**：用户要求必须有一句话点明道理，放在结尾的独立大字卡上，不要只放在字幕里。
- **配乐**：用户在电子乐、Lyria、《千年以后》卡点、Gemini 同节奏版之间比较，最后选了**电子乐和 Lyria**。
- **数字要老实**：模拟结果不好看也照实说。蛇形队的平均等待只从 2.9 分钟降到 2.7 分钟，片中就说「平均只快了一点」，重点放在「被晚到的人超过：38.9% → 0%」。
