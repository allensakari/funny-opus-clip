# particle-math · 光点粒子（数学之美）

数说世界的一种固定风格，源自 S008《数学之美》（2026-10-13，用户选定开头钩子 A，3:28 循环版定稿）；S009《一副扑克牌》纯展示版也用这套引擎。
- 适合：数学对象、公式、算法、概率分布、分形、混沌，能用「一个东西变成下一个东西」串起来的题材。
- 产出：无配音、一镜到底的光点粒子动画，16:9 横版 + 中英字幕；完整版约 2–3.5 分钟，抖音版做成无缝循环。

| 路径 | 内容 |
|---|---|
| `templates/math-beauty-v2/engine.py` | 引擎：相机 `Cam`、粒子系统 `PS`、GL 光点渲染、文字 `tx` / `math_tx` / `caption`、文字变点 `text_pts`、点云变形 `morph` |
| `templates/math-beauty-v2/film.py` | 2:10 版：一镜到底（方程 → 向日葵 → 欧拉 → 傅里叶 → 质数 → 曼德博 → 10³² 深度放大 → Mandelbulb → 洛伦兹 → 收尾） |
| `templates/math-beauty-v2/film_loop.py` | 3:28 循环版：加了 ζ 函数、混沌游戏、超立方体、高尔顿板四幕 |
| `templates/math-beauty-v2/score.py` · `score_loop.py` · `loop_bed.py` | 原创合成配乐、循环音乐床 |
| `episodes/S008_数学之美/` | 封面（`make_covers.py`、`make_cover_en.py`）、srt、发布稿 |

**注意**：引擎在 `templates/math-beauty-v2/`；新一期开工前把要用的文件复制进期目录，免得引擎改动后旧片子重出不了。《千年以后》是商业歌曲，不随仓库提供，只用于测拍，成片用原创合成配乐。

## 和 shushuo 默认流程不同的地方

| 项 | 默认 | particle-math |
|---|---|---|
| 配音 | A2 配音 | **不配音**，中英字幕（`caption(zh, en, …)`） |
| 画面 | 场景切换 + 数据图表 | **一镜到底**：上一个数学对象的光点直接变成下一个，没有硬切 |
| 画幅 / 帧率 | 竖版 30 fps | 横版 1920×1080、60 fps |
| 配乐 | Kevin MacLeod / 合成 | 先卡在《千年以后》的拍点网格上（110.64 BPM，半小节 `h(n) = 1.6811 + 1.0846 n`）；完整版用同一网格写的**原创合成配乐**，抖音版无 BGM、在平台上挂《千年以后》 |
| 数字呈现 | 大数字 + 来源标注 | **公式本身就是画面**：`math_tx` 排公式，数字长在对象上（137.5°、e^{iπ} = −1、10³²） |
| 来源 | 机构 · 年份 | 定理 / 论文 + 年份（Euler 1748、Mandelbrot 1980、Lorenz 1963……），全部列在 YouTube 说明里 |

不变的部分：四个确认节点、`engine/finalize.py` 出片、`brand.py` 黄点水印（`BR.set_canvas(W, H)`）、`transqc.py`。

## 画面语言

- **深色背景 + 彩虹光谱光点**：每个点是一颗发光粒子，颜色按对象的参数着色（相位、迭代次数、牌序）。
- **每个转场都是数学对象自己在变形**：方程溶成种子 → 种子按 √k·e^{2πikθ} 落到单位圆上 → 一个点走到 e^{iπ} = −1 → 那条臂成为傅里叶级数最大的本轮 → 画出的线碎成整数 → 只剩质数 → 质数变成 c 值网格迭代 z → z² + c……`morph(A, B, u)` 做点云对点云的变形，`text_pts` 把文字变成点。
- **一镜到底的相机**：`Cam` 连续运动，`cam_mix` 在两段之间插值，不切镜头。
- **深度放大**：曼德博集合用微扰理论放大到约 1.1 × 10³²（周期 8,007 的迷你曼德博），画面上实时显示倍数。
- 字体：中文霞鹜文楷，英文和数字 Cormorant Garamond（公式用带衬线的斜体变量），`NotoSerifSC` 补 Cormorant 缺的希腊字母。

## 结构

- **开头钩子**（用户 2026-10-13 选 A）：开场就是深度放大 + 一句问句（「一个公式放大 10³² 倍，会看到什么？」），然后回到起点从方程讲起。
- **公式巡礼**：10 个左右的对象一条线串起来，每 2–4 个半小节一个变形，鼓点进来时换大段落。
- **循环版**：音乐床从某个半小节跳回前面（S008：播到 h(81) 跳回 h(9)，跳 72 个半小节），画面在跳点前后接得上，结尾回到开头的漂浮方程，重播无缝。

## 渲染

```
cd skill/styles/particle-math/templates/math-beauty-v2      # 或复制到 episodes/<期>/ 里再跑
python score_loop.py --full                 # 配乐
JOBS=4 python film_loop.py                  # 默认 HOOK=A；--still t … 出样帧
python <ROOT>/engine/finalize.py build/loop/video.mp4 build/loop/score.wav <ROOT>/episodes/S0NN_xxx/发布/xxx.mp4
```
渲染时不要同时跑别的 GPU / 重计算任务（会让某一段静默失败），用 `ffprobe -count_packets` 核对帧数。
